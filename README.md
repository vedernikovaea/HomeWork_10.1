# Проект "HomeWork"

### Задача: разработка виджета банковских операций клиента

#### Установка:
1. Клонируйте репозиторий:
```https://github.com/vedernikovaea/HomeWork_10.1/tree/feature/homework_10_1```


#### Использование:
В данном проекте реализованы несколько функций:
+ masks.py - маскирует номер карты и номер счета
+ widget.py - принимает номер карты и выводит его маску
+ processing.py - принимает список словарей и возвращает необходимые, а также сортирует по дате

#### Тестирование:

Для наших функций реализованы тесты:
test_mask_card_various_inputs - проверяет правильность маскирования номера карты
test_mask_account_card - проверяет корректность распознавания и применения нужного типа максирования в зависимости от типа входных данных (карта или счет)
test_short_accounts
 проверяет корректность сортировки при одинаковых датах
фильтрации списка словарей по заданному статусу state
